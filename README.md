# OpenRune Game Server

Pterodactyl egg for the **OpenRune Game Server** — syncs startup scripts from GitHub and runs the Java game server.

Startup scripts are pulled from the [`openrune-game-server`](https://github.com/Mark7625/custom-pterodactyl-eggs/tree/openrune-game-server) branch of [Mark7625/custom-pterodactyl-eggs](https://github.com/Mark7625/custom-pterodactyl-eggs).

Regenerate `install.sh` and sync the egg JSON after editing scripts:

```bash
python embed-install.py
```
